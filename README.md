# Bashicu Matrix System（BMS）最小化实现

这是 BMS 的 Haskell 最小化实现，旨在提供 BMS 的基础功能。

本项目使用 BSD-3-Clause 许可证。

## BMS 形式

一个 BMS 是形如

```BMS
a00 a01 a02 ... a0n
a10 a11 a12 ... a1n
a20 a21 a22 ... a2n
... ... ... ... ...
am0 am1 am2 ... amn
```

的矩阵，记作

`(a00,a10,a20,...,am0)(a01,a11,a21,...,am1)(a02,a12,a22,...,am2)...(a0n,a1n,a2n,...,amn)`

在本项目中，我们将每一列用用 Haskell 的 `GBashicuMatrix` 类型来表示 BMS，每一列用 `GColumn` 表示，具体为

`GBashicuMatrix [GColumn [a00,a10,a20,...,am0],GColumn [a01,a11,a21,...,am1],GColumn [a02,a12,a22,...,am2],GColumn [a0n,a1n,a2n,...,amn]]`

也就是按列存储，将同一列上的数据储存到一个一维列表。

## 概念

在 BMS 中定义如下概念：

1. 第一行元素的父项为从该元素起，在该元素左边且小于该元素的第一个项。
2. 元素的祖先项为元素的父项、父项的父项等元素。
3. 其余行元素的父项为从该元素起，在该元素左边，小于该元素，且其正上方的项是该元素正上方的项的祖先项的第一个项。
4. 坏根为最后一列中从下往上数的第一个非零项的父项所在的列。
5. 坏部为坏根和末列之间的部分，包含坏根，但是不包含末列。
6. 好部为坏根之前的部分，不包含坏根。
7. 阶差向量为末列和坏根的差值，但是其最后一项始终为零。特别地，如果末列中的第 i+1 行元素为零，则阶差向量的第 i 行元素也为零。

## BMS 条件

一个标准的 BMS 应当满足如下的条件：

1. 首列的所有元素都应当为零。
2. 同列中排在下面的项不大于排在上面的项。
3. 每一个非零项都至多为其父项 +1。

## BMS 展开规则

BMS 的展开规则如下：

1. 空矩阵所对应的序数为 0，即 (∅)=0。
2. 如果 BMS 的最后一列全为零，则它所对应的序数为删去最后一列之后余下部分所对应的序数 +1。
3. 否则保留好部的所有内容不动，将坏部不断复制加在好部后面，每复制一次就将坏部加上一个阶差向量。特别地，如果坏根中元素不是坏部中某项的祖先项，则该项在复制过程中将保持不变。

## 非常规序数与无限序列

本项目用 `GBashicuOrdinal` 表示非常规序数。它由一个末列非全零的标准 BMS 和一个非负整数复制次数组成：

```haskell
data GBashicuOrdinal bms where
    BO :: GBashicuMatrix [GColumn [Integer]] -> Integer -> GBashicuOrdinal [GColumn [Integer]]
```

推荐使用 `mkOrdinal` 构造序数。它会检查 BMS 条件、末列非全零以及复制次数非负。

`ordinalSequence matrix` 返回惰性的无限列表，其各项的复制次数依次为 `0、1、2、...`。使用 `expandedBMS` 可以将其中一项展开为有限 BMS：保留好部，复制指定次数的坏部，并按阶差向量调整受坏根祖先关系影响的元素。有限展开项不包含作为极限标记的原末列，因此复制 0 次可能得到空矩阵或仅包含好部的矩阵。
